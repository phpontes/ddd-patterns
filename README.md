# Domain-Driven Design - Modelagem Tática e Patterns

Este projeto foi desenvolvido como parte do curso da **Plataforma Full Cycle** sobre **Domain Driven Design (DDD)**, com foco em **modelagem tática** e **padrões de projeto** aplicados à construção de sistemas complexos.

## 📚 Objetivo

Explorar os conceitos e práticas de DDD utilizando **TypeScript**, com o propósito de aprender a estruturar projetos reais com base em:

- Entidades
- Aggregates
- Value Objects
- Repositórios
- Services
- Eventos de domínio

## 🛠️ Tecnologias utilizadas

- [Node.js](https://nodejs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Jest](https://jestjs.io/)
- [SWC](https://swc.rs/) – para build e transpile
- [ts-node-dev](https://github.com/wclr/ts-node-dev) – para desenvolvimento com hot reload

## 🚀 Como executar localmente

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/ddd-patterns.git
cd ddd-patterns
```

2. Instale as dependências:

```bash
npm install
```

3. Rode os testes:

```bash
npm test
```

4. Para executar o projeto em modo de desenvolvimento:

```bash
npm run start:dev
```

## ✅ Scripts úteis

| Comando            | Descrição                       |
|--------------------|---------------------------------|
| `npm test`         | Executa os testes com Jest      |
| `npm run build`    | Compila o projeto com SWC       |
| `npm start`        | Roda o projeto compilado        |
| `npm run start:dev`| Executa com hot reload          |

## 🧠 Aprendizados

- Modelagem de domínio rica e orientada a regras de negócio
- Separação clara entre aplicação, domínio e infraestrutura
- Princípios da Clean Architecture aplicados ao DDD
